# Settlingo — инструкции для Claude Code

Settlingo — бесплатное веб-приложение для изучения языков. Сейчас в нём курс турецкого для русскоязычных, живущих в Стамбуле. Следующий курс — английский. Владелец — Антон (Anton-Babaskin), сеньор Linux/инфраструктурный инженер, живёт в Стамбуле, продавать приложение не планирует.

План развития: [`ROADMAP.md`](ROADMAP.md), утверждён 27.11.2026. Работаем по нему по порядку этапов.

---

## Как работать с Антоном

- Отвечать **по-русски**, простым человеческим языком, без жаргона. Новый термин объяснять сразу, в 2–3 словах.
- **Сначала решение, потом объяснение**: что сделано, затем почему так и что под капотом.
- Делать **ровно то, что просит**, максимально просто. Не додумывать и не считать, что он уже что-то сделал, если он этого не сказал.
- Инструкции, где руками действует он сам (настройки GitHub, сервер, телефон), давать **по 1–2 шага** и ждать результат: какую кнопку нажать, где она, что должно появиться.
- Решения, которые за ним (лицензии, траты, публикация, удаление, смена дизайна), — спросить коротко, с рекомендацией.
- Перед большой задачей — короткий план из 3–6 пунктов, потом работа. В конце — таблица «что сделано» и один следующий шаг.

## Запуск и стек

Статический сайт **без сборки**: HTML, CSS, чистый JavaScript, никаких фреймворков и npm-зависимостей в рантайме.

```bash
python3 -m http.server 8000     # http://localhost:8000
```

`index.html` с диска (`file://`) не воспроизводит звук: браузер блокирует `fetch`. Всегда проверять через сервер.

Деплой: пуш в `main` запускает `.github/workflows/pages.yml`, который проверяет синтаксис JS и выкладывает сайт на https://anton-babaskin.github.io/Settlingo/. Pages ещё нужно включить в настройках репозитория (Settings → Pages → Source: **GitHub Actions**). Это делает Антон, см. этап 1 в ROADMAP.

## Архитектура

Скрипты подключаются в `index.html` в таком порядке, все глобальные, без модулей:

| Файл | Что внутри |
|---|---|
| `util.js` | `$`, `$$`, `esc`, `shuffle`, сравнение ответов (`norm`, `cmp`, `fold`), `speakKey()` — ключ фразы для звука, `plural()` для русских окончаний |
| `morph.js` | Турецкая морфология: гармония гласных (`v2`, `v4`), падежи (`nounForm`), времена (`pres`, `past`, `fut`, `aor`, `quest`, `abil`, `must`), генератор заданий `genQ(topic)` и дистракторов `mkOptions()`. Каждая форма возвращает `{parts, why, from}`: части слова для цветного разбора и объяснения по-русски |
| `data.js` | Содержание: `TALK` и `GRAM` (разделы → уроки → шаги), `WG` (группы → темы → слова `[tr, ru, пример?]`), `NOUNS`, `VERBS`, `TOPICS` |
| `audio-index.js` | `window.AUDIO_INDEX = {pack: [[фраза, длина_в_байтах], ...]}` — генерируется, руками не править |
| `audio.js` | `Sound.say(text, rate)`: находит фразу в пакете mp3, вырезает байты, играет как blob. Фолбэк — голос устройства. `Sound.onState()` сообщает интерфейсу, что звук играет |
| `app.js` | Состояние `S` в `localStorage`, повторение `SRS`, сборщики занятий `Sessions`, плеер уроков `Player`, экраны `App` |
| `app.css` | Весь дизайн: токены в `:root`, компоненты, анимации |

### Ключевые понятия в `app.js`

- **Шаги урока** в `data.js` собираются хелперами: `Lr` (карточка нового), `Mc` (выбор ответа), `Bd` (собрать фразу), `Mt` (найди пары), `Gn` (N сгенерированных грамматических заданий). `app.js` добавляет ещё `listen` (аудирование: `mc` / `build` / `type`) и `speak` (скажи вслух).
- **`Player.TYPES`**: у каждого типа шага `render(step)` и `check(step) → {ok, html, say} | null`. Новый тип упражнения = новый ключ в `TYPES`.
- **`SRS`**: коробки Лейтнера, интервалы `[0, 1, 3, 7, 16, 35, 90]` дней. Ключ — `speakKey(турецкая фраза)`. Ошибка возвращает в коробку 1.
- **`S`** хранится под ключом `turkce_v3`. Ключ и форму данных не менять без миграции в `load()`: у людей уже есть прогресс.

## Дизайн-система

Светлый, спокойный, «Apple-like». Подробности и обоснование — `docs/design-review/index.html`.

- Холст `--canvas #F5F8FF`, карточки белые с мягкой тенью `--sh-2`.
- **Один синий** `--blue #2F6BFF` для всего нажимаемого. Зелёный `--good` и красный `--bad` — только для результата ответа. Новые цвета не добавлять.
- Шрифты: **Nunito 800** (`--f-display`, самостоятельно хостится в `fonts/`) — заголовки и турецкие слова. Системный шрифт (`--f-body`) — остальной текст.
- Иконки: только из `ICON` в `app.js`, сетка 24 px, обводка 1.8, скруглённые концы, цвет через `currentColor`. **Никаких эмодзи** в интерфейсе.
- Нажимаемые карточки ответов — с мягкой нижней тенью, которая «проседает» при нажатии.
- Анимации короткие (`--ease`), всё отключается при `prefers-reduced-motion`.
- Пока только светлая тема. Тёмная — этап 3.
- Логотип: облачко речи со «S»-дорожкой, файлы в `brand/`, генерируются `tools/draw-logo.py`. Не перерисовывать без согласия Антона.

## Контент

- Турецкий должен быть **грамматически верным**. Сомневаешься в форме — проверь движком `morph.js` или скажи прямо.
- Русские тексты — простые и живые, как говорят люди, без канцелярита.
- Каждая турецкая строка, которую приложение может произнести, должна иметь запись в `audio/`. После изменения контента пересобрать звук (ниже).
- Объяснения грамматики — через «коробки» и «пары» гласных, а не через термины лингвистики.

## Звук

Пайплайн в `tools/` (запускать из корня репозитория):

```bash
pip install piper-tts                       # плюс ffmpeg с libmp3lame
# голос: tr_TR-dfki-medium.onnx и .onnx.json → tools/voices/
node tools/list-phrases.js                  # → tools/keys.json: все фразы по пакетам
python3 tools/build-audio.py                # → audio/*.mp3 и audio-index.js
```

- Пакеты: 24 kbps CBR моно, клипы подряд, `audio.js` режет их по байтам. Основные пакеты `course` и `words1` грузятся при старте, грамматические — по требованию.
- Турецкий голос: Piper `tr_TR-dfki-medium`, CC BY-NC-SA 4.0.
- Английский голос (решено): **Kokoro-82M v1.0**, Apache-2.0, основной `af_heart`, второй для диалогов `am_michael`. Скрипт для Kokoro нужно написать по образцу `build-audio.py`.
- `tools/keys.json` и `tools/voices/` не коммитить.

## Проверка перед коммитом

1. `for f in *.js; do node --check "$f"; done`
2. Поднять сервер и пройти в браузере **каждый затронутый тип занятия** до экрана «Урок пройден»: урок, повторение, аудирование, «Скажи вслух», грамматика, слова. Консоль без ошибок.
3. Если менялся интерфейс — скриншот на ширине 390 px (iPhone) и сравнение с прошлой версией.
4. Если менялась морфология — проверить формы из таблиц урока на нескольких глаголах и существительных, включая исключения (`git → gidiyor`, `demek → diyor`, смягчение `kitap → kitabı`, апостроф у имён).
5. Если менялся контент — пересобрать звук и README.

## Git

- `main` деплоится автоматически. Крупные задачи — в ветке `stage-N-краткое-имя` и через PR, мелкие правки можно сразу в `main`, если Антон не против.
- Коммиты по-русски, в повелительном или назывном стиле: «Добавить офлайн-режим», «Курс английского: раздел 1».
- Не коммитить: `tools/keys.json`, `tools/voices/`, временные скриншоты.

## Известные особенности

- `mkOptions()` иногда даёт меньше 4 вариантов, когда у формы мало правдоподобных ошибок. Это ожидаемо.
- Иконки нижней панели вставляет `app.js` по атрибуту `data-icon`.
- В `S.srs` ключ — это `speakKey(tr)`, а не исходная строка с пометками в скобках.
- Старая копия приложения опубликована как артефакт на claude.ai. Основная версия теперь — этот репозиторий и GitHub Pages.
