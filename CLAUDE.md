# Blably — инструкции для Claude Code

Blably (раньше Settlingo) — бесплатное веб-приложение для изучения языков **в обе стороны**. Сейчас работает курс турецкого для русскоязычных. Дальше по плану: турецкий для украиноязычных, русский и украинский для турков, в последнюю очередь английский ↔ русский. Владелец — Антон (Anton-Babaskin), сеньор Linux/инфраструктурный инженер, живёт в Стамбуле, продавать приложение не планирует.

Репозиторий на GitHub пока называется `Settlingo` (https://github.com/Anton-Babaskin/Settlingo). Переименовать его может только Антон, без его просьбы ссылки на репозиторий не менять.

План развития: [`ROADMAP.md`](ROADMAP.md), утверждён 27.11.2026 и дополнен в тот же день. Работаем по нему по порядку этапов.

## Курсы: обучение в обе стороны

Курс — это пара «какой язык учим (`target`) ← на каком объясняем (`base`)». Идентификатор курса — `target-base`.

| Курс | target | base | Этап |
|---|---|---|---|
| `tr-ru` | турецкий | русский | работает (сейчас всё в `data.js`) |
| `tr-uk` | турецкий | украинский | 2 |
| `ru-tr` | русский | турецкий | 3 |
| `uk-tr` | украинский | турецкий | 4 |
| `en-ru` | английский | русский | 5, в последнюю очередь |
| `ru-en` | русский | английский | 5, в последнюю очередь |

Порядок работы — строго по `ROADMAP.md`. Английский не начинать раньше этапа 5, даже если кажется, что это быстро.

**Язык интерфейса** выбирается отдельно от курса: `ru`, `uk`, `en` (этап 1), `tr` добавляется на этапе 3 вместе с первым курсом для турков. По умолчанию — язык браузера.

Правила, которые из этого следуют:

- Не писать код, который предполагает «турецкий на экране, русский в ответах». Всё новое должно работать для любой пары `target` / `base`.
- Тексты интерфейса — только через словари `i18n/<язык>.json`, не строками в коде. У всех словарей одинаковый набор ключей (это проверяет тест).
- Объяснения в уроках пишутся на языке `base`, живо и просто, не машинной калькой с другого языка.
- Для курсов `ru-tr` и `uk-tr` грамматику объяснять через сравнение с турецкими окончаниями. Кириллица — отдельный стартовый раздел.
- Пары фраз из `tr-ru` переиспользуются: в `tr-uk` (перевод на украинский) и в `ru-tr` (обратное направление). Турецкая озвучка у них уже есть.

## Как работать с Антоном

- Отвечать **по-русски**, простым человеческим языком, без жаргона. Новый термин объяснять сразу, в 2–3 словах.
- **Сначала решение, потом объяснение**: что сделано, затем почему так и что под капотом.
- Делать **ровно то, что просит**, максимально просто. Не додумывать и не считать, что он уже что-то сделал, если он этого не сказал.
- Инструкции, где руками действует он сам (настройки GitHub, сервер, телефон), давать **по 1–2 шага** и ждать результат: какую кнопку нажать, где она, что должно появиться.
- Решения, которые за ним (лицензии, траты, публикация, удаление, смена дизайна), — спросить коротко, с рекомендацией.
- Перед большой задачей — короткий план из 3–6 пунктов, потом работа. В конце — таблица «что сделано» и один следующий шаг.

## Запуск и стек

Статический сайт **без сборки**: HTML, CSS, чистый JavaScript, никаких фреймворков и npm-зависимостей в рантайме. Код — ES-модули (`import` / `export`, решено 27.11.2026): браузер и Node читают их без сборки. `package.json` только объявляет модули (`"type": "module"`), зависимостей в нём нет.

```bash
python3 -m http.server 8000     # http://localhost:8000
```

`index.html` с диска (`file://`) показывает пустую страницу: браузер не загружает модули с `file://`. Всегда проверять через сервер.

### Платформы

Решено 27.11.2026: **сначала браузерное приложение** (как другой проект Антона, Garage). Под iOS и Android его заворачивает **Capacitor** на этапе 8, тем же кодом. Переписывать на Swift или Kotlin не планируем. Но код пишем так, чтобы такой перенос остался возможным: см. правило «ядро отдельно от экранов» ниже.

Хостинг и публикацию (GitHub Pages или свой сервер) Антон настроит сам позже. **Не добавлять** workflow деплоя, настройки Pages и ссылки на опубликованный сайт без его прямой просьбы.

## Архитектура

`index.html` подключает `audio-index.js` (обычный скрипт) и `ui/main.js` (модуль), остальное подтягивается через `import`.

| `core/text.js` | `shuffle`, `pick`, `random()` (тесты подменяют на предсказуемый через `setRandom`), сравнение ответов (`norm`, `cmp`, `fold`), `speakKey()` — ключ фразы для звука |
| `core/morph.js` | Турецкая морфология: гармония гласных (`v2`, `v4`), падежи (`nounForm`), времена (`pres`, `past`, `fut`, `aor`, `quest`, `abil`, `must`), `NOUNS`, `VERBS`, `TOPICS`, генератор заданий `genQ(topic)` и дистракторов `mkOptions()`. Форма возвращает `{parts, why, from}`, задание — `prompt` данными `{kind, task, word, tr, lead?, q?}` |
| `core/progress.js` | Форма состояния `S` (`fresh`), восстановление из сохранённого текста с переносом из `turkce_v2` / `turkce_v1` (`restore`), опыт, серия дней, отметки плана на день |
| `core/srs.js` | Повторение по интервалам (`createSRS`) |

| `core/run.js` | Ход занятия (`createRunner`): очередь, `prepare`, `check` → данные об ответе, `settle`, повтор ошибок в конце, итог `finish` |

| **`ui/`** | **Экраны: только показ и действия пользователя** |

| `ui/player.js` | Плеер урока: `TYPES` с `render` / `check` для каждого типа шага, шторка с результатом, клавиатура |

| `ui/common.js`, `ui/prompts.js`, `ui/dom.js`, `ui/icons.js` | Кнопки звука, кнопки особых букв, кольцо цели, `lang()` — название изучаемого языка для `{in}`, отрисовка карточек вопроса, `$` / `esc`, иконки `ICON` и знак |

### Правило: ядро отдельно от экранов

Всё, что решает «что правильно» и «что дальше», живёт в **ядре** (`core/`): чистые функции без DOM, `document`, `window`, `localStorage` и звука. Экраны (`ui/`) только показывают данные ядра и передают ему действия пользователя.

| Ядро (`core/`) | Экраны (`ui/`) |
|---|---|
| загрузка и проверка пакетов курса | отрисовка экранов и упражнений |
| морфология и генератор заданий (`morph`) | анимации, звук, клавиатура |
| проверка ответа (`check` возвращает данные, а не HTML) | тексты интерфейса из `i18n/` |
| повторение по интервалам, серия, опыт | чтение и запись `localStorage` |
| сборка занятий (что показать и в каком порядке) | навигация |

Зачем: ядро покрывается тестами в Node без браузера, его переиспользует Capacitor, а при переходе на Swift переписываются только экраны, а не правила. Как проверить: файл из `core/` должен запускаться в `node` без ошибок про `document` или `window`.

Разделено 27.11.2026 (этап 1, первая задача), поведение приложения не изменилось. Правило проверяет `tests/core.test.js`: каждый файл `core/` грузится в Node, в нём нет `document`, `window`, `localStorage`, `fetch`, `innerHTML`. Ядро отдаёт коды, а не тексты интерфейса (`ask: 'meaning'`, `title: 'review'`, `note: 'letters'`), слова для них подставляют экраны. Новый код сразу писать по правилу.

### Ключевые понятия

- **Шаги урока** в `data.js` собираются хелперами: `Lr` (карточка нового), `Mc` (выбор ответа), `Bd` (собрать фразу), `Mt` (найди пары), `Gn` (N сгенерированных грамматических заданий). `core/course.js` добавляет в конец разговорных уроков `listen` (аудирование: `mc` / `build` / `type`) и `speak` (скажи вслух).
- **Новый тип упражнения** = ветка в `prepare` / `check` в `core/run.js` (что правильно) и ключ в `TYPES` в `ui/player.js` (как нарисовать). `check` ядра возвращает данные `{ok, answer, correct, say, …}` или `null`, пока отвечать нечем; HTML собирает экран.
- **Повторение** (`core/srs.js`): коробки Лейтнера, интервалы `[0, 1, 3, 7, 16, 35, 90]` дней. Ключ — `speakKey(турецкая фраза)`. Ошибка возвращает в коробку 1.
- **`S`** хранится под ключом `turkce_v3`. Ключ и форму данных не менять без миграции в `restore()` (`core/progress.js`): у людей уже есть прогресс. Исключение, которое уже учтено: в `S.mist` у старых ошибок `prompt` — готовый HTML, у новых — данные; `gqPrompt()` понимает оба вида.
- **Тексты интерфейса** — `t('раздел.ключ', {параметры})` из `ui/i18n.js`. Ключи сгруппированы по экранам (`today.*`, `player.*`, …). Форма по числу — объект `{"one", "few", "many", "other"}` (в английском `{"one", "other"}`), параметр `{n}`. Изучаемый язык в тексте — `{in}` («Как это {in}?»), значение даёт `lang()` из `ui/common.js` по `langs.<target>.in`. В словарях нет HTML. Фразы на изучаемом языке (Günaydın, Aferin!) — не интерфейс, они в `META` курса. Род в обращениях нейтральный: «Твой ответ», «Получилось». Тест `tests/i18n.test.js` проверяет одинаковые ключи, формы чисел, одинаковые `{параметры}`, что каждый ключ из кода есть в словарях и не осталось лишних, и что в `ui/` нет кириллицы.
- **Язык интерфейса** хранится в `S.lang` (нет поля — «как в браузере»). Сброс прогресса его не трогает. `?lang=uk` в адресе включает язык только на этот визит. `<title>`, `lang` и описание в `index.html` — запасные русские, при запуске их заменяет словарь. Манифест (`manifest.webmanifest`) пока только по-русски.
- **Случайность** только через `random()` / `pick()` / `shuffle()` из `core/text.js`, не `Math.random()` напрямую: так тесты могут сделать её предсказуемой.

## Дизайн-система

Светлый, спокойный, «Apple-like». Подробности и обоснование — `docs/design-review/index.html` (ревью сделано до переименования, поэтому там старое имя Settlingo).

- Холст `--canvas #F5F8FF`, карточки белые с мягкой тенью `--sh-2`.
- **Один синий** `--blue #2F6BFF` для всего нажимаемого. Зелёный `--good` и красный `--bad` — только для результата ответа. Новые цвета не добавлять.
- Шрифты: **Nunito 800** (`--f-display`, самостоятельно хостится в `fonts/`) — заголовки и турецкие слова. Системный шрифт (`--f-body`) — остальной текст.
- Иконки: только из `ICON` в `ui/icons.js`, сетка 24 px, обводка 1.8, скруглённые концы, цвет через `currentColor`. **Никаких эмодзи** в интерфейсе.
- Нажимаемые карточки ответов — с мягкой нижней тенью, которая «проседает» при нажатии.
- Анимации короткие (`--ease`), всё отключается при `prefers-reduced-motion`.
- Пока только светлая тема. Тёмная — этап 3.
- Логотип: строчная «b», которая сама является облачком речи (ножка переходит в хвостик). Плоский, один цвет, без градиентов, без «плитки в плитке». Файлы `brand/blably-*` генерирует `tools/draw-logo.py`. Знак утверждён Антоном 27.11.2026, менять только с его согласия.

## Контент

- Турецкий должен быть **грамматически верным**. Сомневаешься в форме — проверь движком `core/morph.js` или скажи прямо.
- Русские тексты — простые и живые, как говорят люди, без канцелярита.
- Каждая турецкая строка, которую приложение может произнести, должна иметь запись в `audio/`. После изменения контента пересобрать звук (ниже).
- Объяснения грамматики — через «коробки» и «пары» гласных, а не через термины лингвистики.

## Звук

Пайплайн в `tools/` (запускать из корня репозитория):

```bash
pip install piper-tts                       # плюс ffmpeg с libmp3lame
# голос: tr_TR-dfki-medium.onnx и .onnx.json → tools/voices/
node tools/list-phrases.js                  # → tools/keys.json: все фразы по пакетам
python3 tools/build-audio.py                # → audio/*.mp3 и audio-index.js
```

- Пакеты: 24 kbps CBR моно, клипы подряд, `ui/audio.js` режет их по байтам. Основные пакеты `course` и `words1` грузятся при старте, грамматические — по требованию.
- Турецкий голос: Piper `tr_TR-dfki-medium`, CC BY-NC-SA 4.0.
- Английский голос (решено): **Kokoro-82M v1.0**, Apache-2.0, основной `af_heart`, второй для диалогов `am_michael`. Скрипт для Kokoro нужно написать по образцу `build-audio.py`.
- Русский голос (для `ru-tr`, `ru-en`): ещё не выбран. Кандидаты — Piper `ru_RU`, Silero.
- Украинский голос (для `uk-tr`): ещё не выбран. Кандидаты — Piper `uk_UA`, `robinhad/ukrainian-tts`.
- Для любого нового голоса лицензию проверять по первоисточнику, качество — на слух у Антона.
- Когда курсов станет несколько, аудио-пакеты и индекс переедут в `courses/<id>/audio/`.
- `tools/keys.json` и `tools/voices/` не коммитить.

## Проверка перед коммитом

1. `for f in *.js core/*.js ui/*.js tools/*.js; do node --check "$f"; done` и `node --test` (CI сейчас нет, проверять локально)
2. Поднять сервер и пройти в браузере **каждый затронутый тип занятия** до экрана «Урок пройден»: урок, повторение, аудирование, «Скажи вслух», грамматика, слова. Консоль без ошибок.
3. Если менялся интерфейс — скриншот на ширине 390 px (iPhone) и сравнение с прошлой версией.
4. Если менялась морфология — проверить формы из таблиц урока на нескольких глаголах и существительных, включая исключения (`git → gidiyor`, `demek → diyor`, смягчение `kitap → kitabı`, апостроф у имён).
5. Если менялся контент — пересобрать звук и README.

## Известные особенности

- `mkOptions()` иногда даёт меньше 4 вариантов, когда у формы мало правдоподобных ошибок. Это ожидаемо.
- Иконки нижней панели вставляет `ui/screens.js` по атрибуту `data-icon`.
- В `S.srs` ключ — это `speakKey(tr)`, а не исходная строка с пометками в скобках.
- Старая копия приложения (ещё под именем Settlingo) опубликована как артефакт на claude.ai. Основная версия — этот репозиторий.
