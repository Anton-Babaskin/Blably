# План развития Settlingo

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

Цель: превратить Settlingo из курса турецкого в небольшую платформу, где у каждого языка свой **пакет курса**, а интерфейс доступен на русском, украинском и английском. Первый новый курс — английский.

Сроки ориентировочные, при работе по вечерам и выходным. **План утверждён 27 ноября 2026.**

| Этап | Что в итоге | Срок |
|---|---|---|
| 0. Готово | Курс турецкого, новый дизайн, логотип, Pages | ноябрь 2026 |
| 1. Фундамент | Офлайн, интерфейс на 3 языках, тесты, курсы как пакеты | 2–3 недели |
| 2. Курс английского | Английский A1–A2 для русско- и украиноговорящих | 4–6 недель |

## 1. Фундамент

Всё, без чего второй язык добавлять больно.

- [ ] **Включить GitHub Pages.** Settings → Pages → Source: GitHub Actions (делает владелец репозитория), затем перезапустить деплой.
- [ ] **Офлайн и установка.** Service worker: приложение и аудио-пакеты кэшируются, работает без интернета, ставится на экран телефона.
- [ ] **Курсы как пакеты.** Вынести содержание из `data.js` в `courses/tr/` (уроки, словарь, аудио-индекс в JSON). Движок читает любой пакет.
- [ ] **Интерфейс на 3 языках.** Все строки интерфейса в `i18n/ru.json`, `uk.json`, `en.json`, переключатель в настройках, язык по умолчанию из браузера.
- [ ] **Переводы в уроках.** Перевод фраз хранится отдельно для каждого языка интерфейса: `{"tr": "Merhaba", "ru": "Привет", "uk": "Привіт", "en": "Hello"}`.
- [ ] **Тесты.** Тесты морфологии (`node --test`): все формы из таблиц уроков, исключения, смягчения. Запуск в Actions перед деплоем.
- [ ] **Настройки.** Экран с языком интерфейса, дневной целью, скоростью звука, экспортом и импортом прогресса в файл.

## 2. Курс английского

Английский для тех, кто говорит по-русски или по-украински. Уровень A1–A2, упор на работу, переезд и путешествия.

- [ ] **Выбор курса.** При первом запуске и в настройках: турецкий или английский. Прогресс у каждого курса свой.
- [ ] **Разговорный трек, 20 уроков.** Знакомство, работа и созвоны, аэропорт и отель, магазин и кафе, врач, small talk, письма коллегам.
- [ ] **Грамматический трек, 14 уроков.** Артикли, to be, Present Simple и Continuous, Past Simple и неправильные глаголы, Future, модальные глаголы, вопросы.
- [ ] **Генератор заданий для английского.** Формы глаголов (`go → went → gone`, `-s`, `-ing`), артикли, порядок слов в вопросе. Тот же интерфейс, что у турецкого движка.
- [ ] **Словарь.** 500 слов: основа, офис и IT, переезд, город.
- [ ] **Озвучка.** Модель [Kokoro-82M v1.0](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0): основной голос `af_heart`, второй голос для диалогов `am_michael`. Указывать источник в `LICENSE-CONTENT.md`. Решение принято 27.11.2026.
- [ ] **Ловушки для русско- и украиноговорящих.** Отдельные карточки: артикли, «I am agree», порядок слов, ложные друзья переводчика.

## 3. Качество обучения

- [ ] **Тест уровня** на 3 минуты: стартовый урок подбирается сам.
- [ ] **Проверка произношения.** В «Скажи вслух» распознавание речи браузера, где оно есть, с подсветкой слов, которые не распознались.
- [ ] **Диалоги.** Короткие сцены по 6–8 реплик (Kadıköy, вапур, e-Devlet, аренда квартиры) с озвучкой по ролям.
- [ ] **Умное повторение.** Интервалы подстраиваются под человека: трудные фразы чаще, лёгкие реже.
- [ ] **Тёмная тема** в той же палитре.
- [ ] **Доступность.** Проверка контраста, навигация с клавиатуры, подписи для экранных дикторов.

## 4. Синхронизация и друзья

- [ ] **Аккаунт по желанию.** Вход по почте или через Google. Без аккаунта всё работает как сейчас.
- [ ] **Синхронизация прогресса** между телефоном и ноутбуком. Свой сервер (например, PocketBase или Supabase на собственном VPS) с бэкапами.
- [ ] **Друзья.** Ссылка-приглашение, общая серия дней, лёгкий рейтинг за неделю (по желанию).
- [ ] **Напоминания.** Push-уведомление в выбранное время.
- [ ] **Аналитика без слежки.** Plausible или Umami на своём сервере: какие уроки бросают, где больше всего ошибок.

## Принципы, которые не меняем

- **Говорить важнее, чем узнавать.** Упражнения на говорение и диктант в каждом уроке.
- **Спокойный дизайн.** Светлый фон, один синий цвет, без маскотов, штрафов и «потерянных жизней».
- **Работает без регистрации.** Аккаунт нужен только для синхронизации.
- **Простой стек.** Статический сайт без сборки, пока это не начнёт мешать.
