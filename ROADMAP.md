# План развития Blably

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

Цель: превратить Blably в небольшую платформу для изучения языков **в обе стороны**. Каждый курс — отдельный **пакет** с парой «какой язык учим ← на каком языке объясняем». Первые пары:

| Курс | Учим | Объясняем на | Интерфейс | Статус |
|---|---|---|---|---|
| `tr-ru` | турецкий | русском | русский | работает |
| `en-ru` | английский | русском (и украинском) | русский / украинский | этап 2 |
| `ru-tr` | русский | турецком | турецкий | этап 3 |

Сроки ориентировочные, при работе по вечерам и выходным. **План утверждён 27 ноября 2026**, дополнен 27 ноября: проект переименован в Blably, добавлено направление «русский для турков».

| Этап | Что в итоге | Срок |
|---|---|---|
| 0. Готово | Курс турецкого, дизайн, README на трёх языках, лицензии | ноябрь 2026 |
| 1. Фундамент | Офлайн, интерфейс на 4 языках, курсы-пакеты в обе стороны, тесты | 3–4 недели |
| 2. Курс английского | Английский A1–A2 для русско- и украиноговорящих | 4–6 недель |
| 3. Русский для турков | Кириллица, фразы и грамматика с турецким интерфейсом | 6–8 недель |
| 4. Качество обучения | Тест уровня, проверка произношения, диалоги | 4 недели |
| 5. Синхронизация | Прогресс на всех устройствах, друзья | 3–4 недели |
| 6. Мобильные приложения | App Store и Google Play | 3 недели |

Порядок этапов 2 и 3 можно поменять: фундамент готовит оба.

## 1. Фундамент

Всё, без чего второй и третий курсы добавлять больно.

- [ ] **Новый знак для Blably.** Сейчас в облачке «S» от старого имени Settlingo. Нарисовать знак под Blably (например, «B» или облачко-диалог), согласовать с Антоном, обновить `tools/draw-logo.py` и `brand/`.
- [ ] **Курсы как пакеты.** Вынести содержание из `data.js` в `courses/<id>/` (JSON): `course.json` с полями `target` (какой язык учим), `base` (на каком объясняем), `ui` (язык интерфейса), уроки, словарь, аудио-индекс. Движок читает любой пакет. Курс `tr-ru` переносится первым, без изменения поведения.
- [ ] **Выбор курса.** При первом запуске и в настройках: «Я говорю на… → хочу учить…». Прогресс у каждого курса свой (`S.courses[id]`), старый прогресс `turkce_v3` мигрирует в `tr-ru`.
- [ ] **Интерфейс на 4 языках.** Все строки интерфейса в `i18n/ru.json`, `uk.json`, `en.json`, `tr.json`. Язык интерфейса берётся из курса, его можно сменить в настройках.
- [ ] **Двусторонние упражнения.** Сейчас многие шаги предполагают «турецкий на экране, русский в ответах». Обобщить на `target` / `base`: «Что это значит?», «Как это сказать?», аудирование и «Скажи вслух» работают для любой пары.
- [ ] **Офлайн и установка.** Service worker: приложение и аудио-пакеты кэшируются, работает без интернета.
- [ ] **Тесты.** `node --test`: морфология турецкого (все формы из таблиц уроков, исключения, смягчения), загрузка пакетов курса, миграция прогресса.
- [ ] **Настройки.** Курс, язык интерфейса, дневная цель, скорость звука, экспорт и импорт прогресса в файл.

## 2. Курс английского (`en-ru`)

Английский для тех, кто говорит по-русски или по-украински. Уровень A1–A2, упор на работу, переезд и путешествия.

- [ ] **Разговорный трек, 20 уроков.** Знакомство, работа и созвоны, аэропорт и отель, магазин и кафе, врач, small talk, письма коллегам.
- [ ] **Грамматический трек, 14 уроков.** Артикли, to be, Present Simple и Continuous, Past Simple и неправильные глаголы, Future, модальные глаголы, вопросы.
- [ ] **Генератор заданий для английского.** Формы глаголов (`go → went → gone`, `-s`, `-ing`), артикли, порядок слов в вопросе.
- [ ] **Словарь.** 500 слов: основа, офис и IT, переезд, город.
- [ ] **Озвучка.** [Kokoro-82M v1.0](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0): основной голос `af_heart`, второй для диалогов `am_michael`. Решено 27.11.2026.
- [ ] **Ловушки для русско- и украиноговорящих.** Артикли, «I am agree», порядок слов, ложные друзья переводчика.

## 3. Русский для турков (`ru-tr`)

Русский для носителей турецкого: туристическая сфера (Анталья, Аланья, Стамбул), работа с русскоязычными коллегами и клиентами, переезд. Весь интерфейс и объяснения на турецком.

- [ ] **Раздел 0: кириллица.** Буквы, похожие и непохожие на латиницу (`Р = r`, `Н = n`, `В = v`), звуки, которых нет в турецком (`ы`, `щ`, мягкий знак), ударение. Упражнения: прочитать слово, услышать и выбрать, набрать на кириллической клавиатуре.
- [ ] **Разговорный трек, 20 уроков.** Приветствие и знакомство, отель и ресепшен, магазин и рынок, ресторан, такси и дорога, цены и числа, работа с гостями, телефон и мессенджеры.
- [ ] **Грамматический трек.** Объяснять через турецкий: падежи русского сравнивать с турецкими окончаниями (`-de` ↔ «где? в чём?», `-e` ↔ «куда?», `-den` ↔ «откуда?»). Отдельно то, чего в турецком нет: род, согласование прилагательных, вид глагола, прошедшее время по родам.
- [ ] **Генератор заданий для русского.** Склонение существительных по основным типам, спряжение глаголов настоящего времени, прошедшее время по родам, согласование «прилагательное + существительное». Начать с частых правильных слов, исключения — списком.
- [ ] **Словарь.** 500 слов: основа, туризм и сервис, город, работа.
- [ ] **Переиспользовать готовое.** Фразы из `tr-ru` — уже готовые пары «турецкий ↔ русский»: из них собрать стартовый словарь и аудирование, турецкая озвучка у них уже есть.
- [ ] **Озвучка русского.** Подобрать русский голос с лицензией, совместимой с проектом (Apache, MIT, CC BY или CC BY-NC-SA), качество проверить на слух у Антона. Кандидаты: голоса Piper `ru_RU`, Silero. Лицензию проверить по первоисточнику перед использованием.
- [ ] **Ловушки для турков.** Ударение меняет смысл, «ы» и «и», мягкий знак, свободный порядок слов, глагол не обязательно в конце.

## 4. Качество обучения

- [ ] **Тест уровня** на 3 минуты: стартовый урок подбирается сам.
- [ ] **Проверка произношения.** В «Скажи вслух» распознавание речи браузера, где оно есть, с подсветкой слов, которые не распознались.
- [ ] **Диалоги.** Короткие сцены по 6–8 реплик с озвучкой по ролям, для каждого курса свои.
- [ ] **Умное повторение.** Интервалы подстраиваются под человека: трудные фразы чаще, лёгкие реже.
- [ ] **Тёмная тема** в той же палитре.
- [ ] **Доступность.** Проверка контраста, навигация с клавиатуры, подписи для экранных дикторов.

## 5. Синхронизация и друзья

- [ ] **Аккаунт по желанию.** Вход по почте или через Google. Без аккаунта всё работает как сейчас.
- [ ] **Синхронизация прогресса** между телефоном и ноутбуком. Свой сервер (например, PocketBase или Supabase на собственном VPS) с бэкапами.
- [ ] **Друзья и тандем.** Ссылка-приглашение, общая серия дней. Тандем: турок учит русский, русскоязычный — турецкий, занимаются вместе.
- [ ] **Напоминания.** Push-уведомление в выбранное время.
- [ ] **Аналитика без слежки.** Plausible или Umami на своём сервере.

## 6. Мобильные приложения

## Принципы, которые не меняем

- **Говорить важнее, чем узнавать.** Упражнения на говорение и диктант в каждом уроке.
- **Спокойный дизайн.** Светлый фон, один синий цвет, без маскотов, штрафов и «потерянных жизней».
- **Работает без регистрации.** Аккаунт нужен только для синхронизации.
- **Простой стек.** Статический сайт без сборки, пока это не начнёт мешать.
- **Хостинг и публикацию Антон настраивает сам.** Деплой в план не входит, без его просьбы не трогать.
