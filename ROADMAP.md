# План развития Blably

[English](README.md) · [Українська](README.uk.md) · [Русский](README.ru.md)

Цель: превратить Blably в небольшую платформу для изучения языков **в обе стороны**. Каждый курс — отдельный **пакет** с парой «какой язык учим ← на каком языке объясняем».

## Курсы

| Курс | Учим | Объясняем на | Кому | Этап |
|---|---|---|---|---|
| `tr-ru` | турецкий | русском | русскоязычным | работает |
| `tr-uk` | турецкий | украинском | украиноязычным | 2 |
| `ru-tr` | русский | турецком | туркам | 3 |
| `uk-tr` | украинский | турецком | туркам | 4 |
| `en-ru` | английский | русском | русскоязычным | 5, в последнюю очередь |
| `ru-en` | русский | английском | англоязычным | 5, в последнюю очередь |

## Интерфейс

Приложение переводится на **русский, украинский и английский** (этап 1). Человек выбирает язык интерфейса сам, по умолчанию берётся язык браузера. **Турецкий интерфейс** добавляется вместе с первым курсом для турков (этап 3): без него туркам учиться неудобно.

## 1. Фундамент

Всё, без чего новые курсы добавлять больно.

- [x] **Ядро отдельно от экранов.** Вынести правила в `core/` (чистые функции без DOM и `localStorage`): загрузка курса, морфология, проверка ответов, повторение, сборка занятий. Экраны — в `ui/`. Ядро запускается и тестируется в Node. Это делает возможным Capacitor и, если понадобится, перенос на Swift без переписывания правил. Делать первым, остальные задачи этапа строятся на нём.
- [x] **Интерфейс на 3 языках.** Все строки интерфейса в `i18n/ru.json`, `uk.json`, `en.json`. Переключатель в настройках, по умолчанию язык браузера. Строк интерфейса в коде больше не остаётся.
- [ ] **Курсы как пакеты.** Вынести содержание из `data.js` в `courses/<id>/` (JSON): `course.json` с полями `target` (какой язык учим) и `base` (на каком объясняем), уроки, словарь, аудио-индекс. Движок читает любой пакет. Курс `tr-ru` переносится первым, без изменения поведения.
- [ ] **Выбор курса.** При первом запуске и в настройках: «Я говорю на… → хочу учить…». Прогресс у каждого курса свой (`S.courses[id]`), старый прогресс `turkce_v3` мигрирует в `tr-ru`.
- [ ] **Двусторонние упражнения.** Сейчас многие шаги предполагают «турецкий на экране, русский в ответах». Обобщить на `target` / `base`: «Что это значит?», «Как это сказать?», аудирование и «Скажи вслух» работают для любой пары.
- [ ] **Офлайн и установка.** Service worker: приложение и аудио-пакеты кэшируются, работает без интернета.
- [ ] **Тесты.** `node --test`: морфология турецкого (все формы из таблиц уроков, исключения, смягчения), загрузка пакетов курса, миграция прогресса, полнота переводов интерфейса (в каждом словаре одинаковые ключи).
- [ ] **Настройки.** Курс, язык интерфейса, дневная цель, скорость звука, экспорт и импорт прогресса в файл.

## 2. Турецкий для украинцев (`tr-uk`)

Самый быстрый новый курс: уроки, турецкие фразы и звук уже есть в `tr-ru`.

- [ ] Перевести объяснения, переводы фраз и словарь `tr-ru` на украинский, живым языком, а не машинной калькой с русского.
- [ ] Грамматические подсказки движка (`why` в `morph.js`) вынести в словари и перевести на украинский.
- [ ] Интерфейс курса — украинский.
- [ ] Проверить каждый урок целиком: переводы, ответы в упражнениях, «Скажи вслух».

## 3. Русский для турков (`ru-tr`)

Русский для носителей турецкого: туристическая сфера (Анталья, Аланья, Стамбул), работа с русскоязычными коллегами и клиентами, переезд. Объяснения и интерфейс на турецком.

- [ ] **Турецкий интерфейс.** Добавить `i18n/tr.json`.
- [ ] **Раздел 0: кириллица.** Буквы, похожие и непохожие на латиницу (`Р = r`, `Н = n`, `В = v`), звуки, которых нет в турецком (`ы`, `щ`, мягкий знак), ударение. Упражнения: прочитать слово, услышать и выбрать, набрать на кириллической клавиатуре.
- [ ] **Разговорный трек, 20 уроков.** Приветствие и знакомство, отель и ресепшен, магазин и рынок, ресторан, такси и дорога, цены и числа, работа с гостями, телефон и мессенджеры.
- [ ] **Грамматический трек.** Через сравнение с турецким: падежи русского рядом с турецкими окончаниями (`-de` ↔ «где? в чём?», `-e` ↔ «куда?», `-den` ↔ «откуда?»). Отдельно то, чего в турецком нет: род, согласование прилагательных, вид глагола, прошедшее время по родам.
- [ ] **Генератор заданий для русского.** Склонение существительных по основным типам, спряжение в настоящем времени, прошедшее время по родам, согласование «прилагательное + существительное». Начать с частых правильных слов, исключения — списком.
- [ ] **Словарь.** 500 слов: основа, туризм и сервис, город, работа.
- [ ] **Переиспользовать готовое.** Пары фраз из `tr-ru` — уже готовые «турецкий ↔ русский»: из них собрать стартовый словарь и аудирование. Турецкая озвучка у них есть.
- [ ] **Озвучка русского.** Голос с лицензией, совместимой с проектом (Apache, MIT, CC BY или CC BY-NC-SA). Кандидаты — Piper `ru_RU`, Silero. Лицензию проверить по первоисточнику, качество — на слух у Антона.
- [ ] **Ловушки для турков.** Ударение меняет смысл, «ы» и «и», мягкий знак, свободный порядок слов.

## 4. Украинский для турков (`uk-tr`)

Повторяет структуру `ru-tr`: кириллица, разговорный трек, грамматика через турецкий.

- [ ] **Кириллица по-украински.** Буквы `і`, `ї`, `є`, `ґ`, апостроф, отличия от русского алфавита.
- [ ] **Разговорный трек, 20 уроков** по тем же темам, что `ru-tr`, но с украинскими реалиями.
- [ ] **Грамматика и генератор заданий** для украинского: падежи (включая звательный), спряжение, прошедшее время по родам.
- [ ] **Словарь**, 500 слов.
- [ ] **Озвучка украинского.** Голос с совместимой лицензией. Кандидаты — Piper `uk_UA`, проект `robinhad/ukrainian-tts`. Лицензию и качество проверить.
- [ ] **Ловушки для турков**, в том числе путаница с русским, если человек учит оба языка.

## 5. Английский ↔ русский (`en-ru`, `ru-en`) — в последнюю очередь

- [ ] **`en-ru`: английский для русскоязычных.** A1–A2: 20 разговорных уроков (работа и созвоны, аэропорт и отель, магазин и кафе, врач, small talk, письма) и 14 грамматических (артикли, to be, Present Simple и Continuous, Past Simple и неправильные глаголы, Future, модальные, вопросы). Генератор форм английских глаголов. 500 слов. Ловушки: артикли, «I am agree», порядок слов.
- [ ] **`ru-en`: русский для англоязычных.** Переиспользует материалы `ru-tr` (кириллица, разговорный трек, генератор русской морфологии) с объяснениями на английском.
- [ ] **Озвучка английского.** [Kokoro-82M v1.0](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0): основной голос `af_heart`, второй для диалогов `am_michael`. Решено 27.11.2026.

## 6. Качество обучения

- [ ] **Тест уровня** на 3 минуты: стартовый урок подбирается сам.
- [ ] **Проверка произношения.** В «Скажи вслух» распознавание речи браузера, где оно есть, с подсветкой слов, которые не распознались.
- [ ] **Диалоги.** Короткие сцены по 6–8 реплик с озвучкой по ролям, для каждого курса свои.
- [ ] **Умное повторение.** Интервалы подстраиваются под человека: трудные фразы чаще, лёгкие реже.
- [ ] **Тёмная тема** в той же палитре.
- [ ] **Доступность.** Проверка контраста, навигация с клавиатуры, подписи для экранных дикторов.

## 7. Синхронизация и друзья

- [ ] **Аккаунт по желанию.** Вход по почте или через Google. Без аккаунта всё работает как сейчас.
- [ ] **Синхронизация прогресса** между телефоном и ноутбуком. Свой сервер (например, PocketBase или Supabase на собственном VPS) с бэкапами.
- [ ] **Друзья и тандем.** Ссылка-приглашение, общая серия дней. Тандем: турок учит русский или украинский, его друг — турецкий, занимаются вместе.
- [ ] **Напоминания.** Push-уведомление в выбранное время.
- [ ] **Аналитика без слежки.** Plausible или Umami на своём сервере.

## Принципы, которые не меняем

- **Говорить важнее, чем узнавать.** Упражнения на говорение и диктант в каждом уроке.
- **Спокойный дизайн.** Светлый фон, один синий цвет, без маскотов, штрафов и «потерянных жизней».
- **Работает без регистрации.** Аккаунт нужен только для синхронизации.
- **Простой стек.** Статический сайт без сборки, пока это не начнёт мешать.
- **Хостинг и публикацию Антон настраивает сам.** Деплой в план не входит, без его просьбы не трогать.
